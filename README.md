# BootCamp EloGroup

Este repositório reúne os entregáveis desenvolvidos durante o BootCamp EloGroup, além de documentos de apoio às análises e ao processamento do case.

## Conteúdo do projeto

- **Dados originais e derivados**, organizados de forma reprodutível para apoiar as etapas de tratamento, análise e geração dos resultados.
- **Agente de IA em Python**, desenvolvido em notebook (`.ipynb`).
- **Análise exploratória**, com insights relevantes sobre os dados e construção da árvore de hipóteses, também disponibilizada em notebook (`.ipynb`).
- **Dashboard executivo em HTML**, com visualização dos principais resultados e indicadores do projeto.
- **Pitch executivo** apresentado à banca avaliadora.
