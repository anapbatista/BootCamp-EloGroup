# BootCamp EloGroup

Este repositório reúne os entregáveis desenvolvidos no contexto do BootCamp Elo Group, uma formação intensiva focada em dados, tecnologia, inovação e tomada de decisão, com ênfase em projetos práticos e na aplicação de metodologias analíticas em cenários reais de negócio.

## Sobre o BootCamp Elo Group

O BootCamp da Elo Group é uma iniciativa de capacitação que conecta aprendizado técnico e estratégico para desenvolver habilidades em análise de dados, inteligência artificial, visualização de informações e comunicação de resultados. A proposta do programa é preparar participantes para resolver desafios reais com abordagem prática, colaborativa e orientada a impacto de negócio.

Dentro desse contexto, este projeto representa uma aplicação concreta dos conceitos aprendidos durante o programa: desde a coleta e organização dos dados, passando pela análise exploratória, até a construção de insights, hipóteses e entregáveis executivos.

## Conteúdo do projeto

- Dados originais e derivados, organizados de forma reprodutível para apoiar o tratamento, a análise e a geração dos resultados.
- Agente de IA em Python, desenvolvido em notebook (`.ipynb`).
- Análise exploratória com insights relevantes e árvore de hipóteses, também disponibilizada em notebook (`.ipynb`).
- Dashboard executivo em HTML para apresentação visual dos principais resultados.
- Pitch executivo apresentado à banca avaliadora.
